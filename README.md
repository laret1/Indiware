indiware

Una colección de pequeños minijuegos inspirados en algunos de mis juegos favoritos. El proyecto reúne diferentes estilos y mecánicas en un solo lugar.

 Minijuegos incluidos
 Mario Bros — Minijuego inspirado en las plataformas clásicas.
 Undertale — Sistema de esquivar ataques inspirado en sus combates.
 Balatro — Minijuego basado en la idea de crear combinaciones de cartas.
 Among Us — Minijuego inspirado en las mecánicas de impostores y tripulación.
 Cookie Clicker — Minijuego de hacer clic para conseguir recursos y aumentar la producción.
 Uso de IA

La mayor parte del proyecto fue realizada por mí.

Utilicé IA únicamente como apoyo puntual, principalmente para:

Ayudarme a encontrar y entender algunos errores.
Darme orientación cuando no sabía por qué algo no funcionaba.
Resolver dudas específicas durante el desarrollo.

No utilicé IA para crear los minijuegos completos.

Objetivo

El objetivo de este proyecto es practicar diferentes áreas del desarrollo de videojuegos, experimentando con mecánicas de distintos juegos y aprendiendo mientras los implemento.

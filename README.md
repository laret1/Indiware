#  Indieware

A collection of small minigames inspired by iconic games such as Super Mario Bros., Undertale, Balatro, Among Us, and Cookie Clicker.



##  Try it

**[ Play the game]((https://laret1.itch.io/indiware))**

##  Quick Start

1. Download the latest version from the **Releases** section.
2. Extract the downloaded file.
3. Run the game executable.

##  Features

*  **Mario Bros.** — A small platforming minigame inspired by classic Mario gameplay.
*  **Undertale** — Dodge incoming attacks using an Undertale-inspired battle system.
*  **Balatro** — Make card combinations in a simplified card-based minigame.
*  **Among Us** — A short minigame inspired by the game's tasks and impostor mechanics.
*  **Cookie Clicker** — Click to collect cookies and increase your production.
*  **Multiple game styles** — Each minigame focuses on a different gameplay mechanic.

##  How to Run Locally

### Requirements

* [godot.4.7.2]
* A computer capable of running the game.

### Running the project

1. Clone or download this repository.
2. Open the project in the game engine.
3. Run the main scene/project.



Then open the project and run it.

 How It Works

The project is divided into several independent minigames. Each one focuses on recreating a recognizable gameplay idea while keeping the scope small enough to experiment with different mechanics.

The goal was not to recreate the original games completely, but to make short playable versions that capture the main idea of each one.

##  Use of AI

AI was used **only as a small development aid**, mainly to help identify and understand programming errors when I got stuck.

The gameplay, implementation, and project development were done by me. I did not use AI to generate the complete minigames.
